# Idiomas / Languages

- Português de Portugal é o idioma principal: `/`.
- Inglês está em `/en/`. A navegação e os títulos da interface usam `src/lib/i18n.ts`.
- Alterar rótulos e textos de interface: editar as duas entradas de `src/lib/i18n.ts`.
- Os conteúdos escritos pelos grupos (ficheiros Markdown) **mantêm-se no idioma original** no protótipo v3. O seletor muda a interface, não traduz automaticamente os artigos.
- Numa versão posterior, podem ser introduzidas variantes `pt`/`en` por projeto, com fallback explícito sem duplicar a autoria.
- Não colocar instruções de edição nas páginas públicas. Usar apenas `docs/` e `templates/`.
