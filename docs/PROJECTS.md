# Add or update a project

Add `src/content/groups/<your-group>/projects/<name>.md` (or edit `overview.md`).

```md
---
title: "A new project"
summary: "One sentence: what it is and why it matters."
status: "Active"
tags: ["satellite", "engineering"]
# image: "/images/cubesat/project.jpg"
# externalUrl: "https://example.org"
---

Two or three short paragraphs of public-facing project information.

Who participates, what visitors can learn and where they can find more information.
```

Use only publicly releasable material. Avoid heavy PDF attachments; link to existing group or institutional resources where possible. Public-facing content should speak to prospective students, school visitors and external collaborators.
