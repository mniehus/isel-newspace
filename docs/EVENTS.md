# Add an event

Place group events inside `src/content/groups/<group>/events/` or cross-cutting activities inside `src/content/shared/events/`.

```md
---
title: "Workshop on space systems"
date: 2027-03-12
scope: "ISEL NewSpace"
location: "ISEL, Lisbon"
summary: "A short public description of the activity."
featured: false
# url: "https://example.org"
---

Details and registration information.
```

Valid scope values: `ISEL NewSpace`, `ISEL group`, `Lisbon & regional`, `Portugal`, `Europe & international`. Do not publish placeholder dates as confirmed events. For external events add a link to the organiser and verify dates and eligibility before publication.
